# Java Operators Guide

This repository contains examples and explanations of Java operators, which are essential for performing logic and calculations in Java.

## Types of Operators

### 1. Arithmetic Operators
Used for mathematical calculations like addition and multiplication.
* `+` (Addition)
* `-` (Subtraction)
* `*` (Multiplication)
* `/` (Division)
* `%` (Modulus - returns the remainder)

### 2. Relational Operators
Used to compare two values. They return a `boolean`.
* `==` (Equal to)
* `!=` (Not equal to)
* `>` (Greater than)
* `<` (Less than)

### 3. Logical Operators
Used to combine multiple boolean expressions.
* `&&` (Logical AND)
* `||` (Logical OR)
* `!` (Logical NOT)
